## Capability Inventory

> 以下能力来自 OpenSpec 转换，部分（articles/albums 集合、相册与文章路由）尚未在
> 当前代码中接线，属于目标状态。

### content publishing

- Intent: Define how the Astro blog manages Markdown articles and notes through typed content collections.
- Source: `openspec/specs/content-publishing/spec.md`
- Dependencies: `Astro Content Collections`, `astro:content`, `@astrojs/sitemap`, `Shiki (Astro 内置)`
- Constraints: 重复 slug MUST 在构建期报错; draft 文章在生产环境 MUST 隐藏并返回 404; RSS 最多包含最近 20 篇非 draft 文章

### photo gallery

- Intent: Define the photo gallery collection, album pages with GLightbox, and image note card streams.
- Source: `openspec/specs/photo-gallery/spec.md`
- Dependencies: `Astro Content Collections`, `astro:assets`, `GLightbox`
- Constraints: images 路径 MUST 相对 src/assets/gallery/<album-slug>/ 目录; images 为空或缺失时 npm run build MUST 报错; 图片通过 astro:assets 构建期生成 WebP/AVIF 响应式缩略图

### reader comments

- Intent: Define Giscus-based comments integration on article and note detail pages.
- Source: `openspec/specs/reader-comments/spec.md`
- Dependencies: `Giscus`, `GitHub Discussions`
- Constraints: Giscus 配置为空占位时 MUST 不阻断构建; mapping MUST 设为 pathname

### site deployment

- Intent: Define automated GitHub Pages deployment, pre-build testing, base path, and SEO metadata requirements.
- Source: `openspec/specs/site-deployment/spec.md`
- Dependencies: `withastro/action@v3`, `actions/deploy-pages@v4`, `GitHub Actions`, `astro.config.ts`
- Constraints: workflow MUST 使用 withastro/action@v3 构建，actions/deploy-pages@v4 部署; base MUST 为 /git-novel 以匹配 Pages 路径; canonical 与 og:url MUST 输出绝对 URL
